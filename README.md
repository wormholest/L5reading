<h2>文章結構：因果 Cause &amp; Effect</h2>
<div class="chain"><b>威尼斯很美卻有風險</b><i>→</i><b>2 個自然成因</b><i>+</i><b>2 個人為成因</b><i>→</i><b>淹水惡化</b><i>→</i><b>呼籲全人類行動</b></div>
<div class="c"><h3><span class="tag">P1</span>引言</h3>威尼斯建於海上千年，靠海上貿易起家，今日以潟湖、古橋、運河吸引每年數千萬遊客，但近年因<b>自然條件與人類活動</b>而下沉、淹水。<p class="mu en">關鍵：set…apart from, prominent, commerce, tranquil, vast</p></div>
<div class="c"><h3><span class="tag">P2</span>兩個自然成因</h3>① <b>acqua alta</b>（高水位）：冬季高潮＋強風＋大浪使海水湧入。② <b>natural subsidence</b>（自然下陷）：建於沼澤、地基不穩；又位於 Adriatic Plate 上，板塊正移到 Apennine Mountains 下方，使地面更低。<p class="mu en">關鍵：In consequence, due to, is causing</p></div>
<div class="c"><h3><span class="tag">P3</span>兩個人為成因</h3>① 1930 年代起為工業目的<b>抽水</b>，使下陷加速（1970 年代禁止，但已造成傷害，近百年下沉約 25 cm）。② <b>燃燒化石燃料</b>→ 二氧化碳 → 暖化 → 冰帽融化 → 海平面上升；預估 2100 年水位升高達 53 cm。<p class="mu en">關鍵：As if…, contend with, resulted in, has led to</p></div>
<div class="c"><h3><span class="tag">P4</span>結果與對策</h3>近一世紀淹水頻率由每年不到 10 次增至 60 次以上。1966 年 11 月 194 cm（紀錄最高，淹 22 小時）；2019 年 187 cm（當年 5 次超過 140 cm）。政府推出 <b>MOSE</b> 可移動屏障擋高潮。<p class="mu en">關鍵：As a matter of fact, swept, extraordinary</p></div>
<div class="c"><h3><span class="tag">P5</span>結論</h3>威尼斯是對人類的<b>考驗</b>：能否共同努力遏止暖化、保護地球給後代。屬於「呼籲行動 call to action」型結論，未引入新想法。<p class="mu en">關鍵：owing to, far from, joint, curb, acknowledge</p></div>

<h2>句型：as if + S + were / V-ed；as if + S + had + p.p.</h2>
<div class="c">as if＝「彷彿、好像」，後接<b>與事實相反</b>的狀況，用假設語氣：<br>① 與主要動詞<b>同時</b> → be 用 <b>were</b>，一般動詞用過去式。<br>② 比主要動詞<b>更早</b> → <b>had + p.p.</b><p class="en">She often dresses <b>as if she were</b> a superstar.<br>Laura talked <b>as if she had gone</b> to the concert.<br>課文：<b>As if</b> land subsidence <b>were</b> not a serious enough problem, the city also has to contend with climate change.</p>
<p class="mu">口訣：事實是現在，as if 用過去；事實是過去，as if 用過去完成。</p></div>
<div class="c warn"><b>補充：</b>as if 句首的用法（課文）＝「彷彿…還不夠似的，還要…」，常表示「禍不單行」。<br>as if / as though 可互換；口語常用 was，但考試與正式寫作請用 <b>were</b>。<br>也可接真實可能的情況（如 It looks as if it is going to rain.）用直說語氣。</div>
<h2>時態與時間標記</h2>
<div class="c w"><table><tr><th>時態</th><th>用法</th><th>時間標記</th><th>課文例</th></tr>
<tr><td>現在簡單</td><td>事實、恆常現象</td><td>every day, in winter</td><td class="en">Acqua alta commonly occurs in winter.</td></tr>
